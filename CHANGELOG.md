# Changelog

## v1.0
- MergeSort with reusable buffer, insertion-sort cut-off and ordered-halves check
- Randomized QuickSort with 3-way partition and smaller-first recursion
- Deterministic Select (median-of-medians, groups of 5)
- Closest Pair of Points (Θ(n log n), y-order maintained by merging)
- Metrics: time, max recursion depth, comparisons, swaps, allocations, recursive calls
- Experiments on 7 sizes × 4 input types, CSV output, plots and README report
- 16 JUnit 5 correctness tests
